# ミテル — あなたを見ている

一人称・360°の3Dホラー。廃病棟で鍵を集め、非常口から外へ逃げてください。攻撃する手段はありません。見つかったら逃げるか、隠れてやり過ごすだけです。

- 遊ぶ: https://coconosuke.github.io/miteru/
- 版: v0.4.0
- 横持ち推奨・ヘッドホン推奨

## iPhoneのホーム画面に入れる
1. Safari で上のURLを開く
2. 共有ボタン →「ホーム画面に追加」（iOS 26 では、アドレスバーの「…」の中に共有ボタンがあります）
3. ホーム画面のアイコンから開くと、全画面で遊べます

ホーム画面のアプリと、Claude の中で遊ぶ版は、保存（設定・名前・記録）が別々です。移すときは「設定 → データ → 引き継ぎコード」を使ってください。

## みんなで遊ぶ（2〜4人）
1. ひとりがタイトルの「みんなで遊ぶ」→「部屋を作る」
2. 出てきた5文字のコードか「招待リンクを送る」で友だちに知らせる（リンクを開くとコードが入った状態になります）
3. 友だちは「コードで入る」。そろったらホストが難易度を選んで「始める」

- 通信は公開のMQTTサーバー（EMQX・HiveMQ・Mosquitto）を中継に使い、つながればお互いの端末どうしで直接（WebRTC）やりとりします。送るのは名前・見た目・動きだけです。
- 回線によっては直接つながらず、中継のままになります（少し遅れることがあります）。
- ホストがページを閉じたり、別のアプリに切り替えたりすると、全員の試合が止まります。
- 版がちがうと一緒に遊べません。両方とも読み込み直してください。

## ファイル
- `index.html` … ゲーム本体（音・画像を含めて1ファイル）
- `sw.js` `manifest.webmanifest` `icon-*.png` … ホーム画面のアプリ用
- `source-bundle.txt` … ソース一式。`node tools/unbundle.mjs source-bundle.txt <出力先>` で元のファイルに戻せます
- `DESIGN.md` … 設計メモ（仕様・数値・調整の記録）

個人で遊ぶために作ったものです。
